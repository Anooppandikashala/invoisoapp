Installation guide

Three steps and you're creating invoices in under a minute.

  1. Run the installer

    Open the downloaded invoiso-x.x.x-windows-setup.exe. If Windows SmartScreen appears, click More info → Run anyway.

  2. Follow the setup wizard

    The default options are fine. Click Install; it finishes in under a minute.

  3. Open Invoiso and sign in

    Launch it from the Start Menu or desktop shortcut. Sign in with username admin and password admin, then set your own password.

  1. Open the disk image

    Double-click the downloaded .dmg file and drag Invoiso into your Applications folder.

  2. Allow it on first launch

    Open Invoiso from Applications. If macOS blocks it, go to System Settings → Privacy & Security and allow Invoiso to run.

  3. Sign in

    Use username admin and password admin, then set your own password.

  1. Install with one command

    Recommended. Fetches the latest release from GitHub and installs it (needs curl and sudo):

    curl -fsSL https://invoiso.co.in/install.sh | bash -s -- --deb

    Not on Ubuntu? Use the AppImage installer instead (no sudo needed):

    curl -fsSL https://invoiso.co.in/install.sh | bash -s -- --appimage

  2. Or install the file manually

    For a downloaded DEB package:

    sudo apt install ./Invoiso-*.deb

    For a downloaded AppImage, make it executable and run it:

    chmod +x Invoiso-*.AppImage

  3. Open Invoiso and sign in

    Find Invoiso in your app launcher. Sign in with username admin and password admin, then set your own password.

DEB packages are supported on Ubuntu 22.04 and 24.04. The AppImage runs on any 64-bit distribution and keeps your data in ~/.local/share/invoiso/.

    Questions before you download

    Is Invoiso really free?

    Yes. Invoiso is free and open source. There is no subscription, no trial period and no account to create.

    Why does Windows show a SmartScreen warning?

    SmartScreen warns about apps that are not yet widely downloaded. Invoiso is open source and its code is public on GitHub. Click More info, then Run anyway to continue.

    What is the default login?

    The default login credentials are username admin and password admin. You are asked to set a new password the first time you sign in.

    Can I create GST invoices with Invoiso?

    Yes. Invoiso creates GST-ready PDF invoices for small businesses, with your company details, tax rates and totals, and it works fully offline.

    Does Invoiso need an internet connection?

    No. After installation Invoiso works fully offline and your billing data stays on your own computer.

    Which Linux file should I download?

    Use the DEB package on Ubuntu 22.04 or 24.04. On any other 64-bit distribution, use the AppImage, which runs without installation.
